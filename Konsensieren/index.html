Wem möchten Sie zugeordnet werden?

Bewerten Sie für jede der fünf Personen, wie viel Widerstand Sie gegen eine Zuordnung zu ihr hätten: 0 heißt „passt mir gut“, 10 heißt „auf keinen Fall“. Die Auswertung ordnet alle so zu, dass möglichst wenig Widerstand entsteht und jede Person ungefähr gleich viele Mitarbeitende bekommt.

Auswertung

Zurücksetzen

Löscht alle Codes, Stimmen und Ergebnisse. Das lässt sich nicht rückgängig machen.

Auswertung aus Datei

Für Stimmen, die Sie anders gesammelt haben, zum Beispiel mit Microsoft Forms. Exportieren Sie die Antworten nach Excel und kopieren Sie die Spalten Code und die fünf Namen samt Kopfzeile hier hinein, oder laden Sie eine CSV-Datei.

Code-Zettel ohne Datenbank

Erzeugt zufällige Codes, die Teilnehmende in ein Formular eintragen. Diese Codes werden nirgends gespeichert.

So richten Sie Microsoft Forms dafür ein
  1. Frage 1: Text „Ihr Code“ (Pflicht).
  2. Fragen 2–6: je eine Bewertung oder Zahl 0–10 für A. Rupprecht, Ch. Schön, J. Glaser, E. Ohland und Unbekannt (Pflicht).
  3. Einstellungen: „Nur Personen in meiner Organisation“, „Namen aufzeichnen“ aus, „Eine Antwort pro Person“ an.
  4. Nach Ende: Antworten in Excel öffnen, Spalten Code und die fünf Namen hier einfügen.

Anonymität: Gespeichert werden keine Namen, nur der verschlüsselte Code und die fünf Werte. Wer welchen Code hat, weiß niemand, weil die Zettel verlost werden.
